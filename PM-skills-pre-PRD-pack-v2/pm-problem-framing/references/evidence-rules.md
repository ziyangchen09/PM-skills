# 问题证据规则

## 证据类型

| 类型 | 可支持的判断 |
|---|---|
| 用户原话 | 感受、理解、主观目标 |
| 行为观察 | 实际操作路径、卡点、绕行 |
| 日志或埋点 | 频率、顺序、失败、耗时 |
| 工单或客服记录 | 问题分布和重复出现情况 |
| 业务数据 | 影响规模和结果变化 |
| 专业规范 | 合规、安全和业务规则 |
| 历史决策 | 已确认边界和约束 |
| 竞品资料 | 方案空间，不直接证明本产品问题 |
| 内部意见 | 组织判断，不等同于用户证据 |

## 证据与结论

每个重要结论应能回答：

- 来源是什么？
- 支持的是事实、原因还是影响？
- 是否存在反例？
- 是否来自同一批样本？
- 是否适用于当前用户和场景？
- 是否已经过期？

## 可信度

- 高：多来源一致，且有行为或数据支持。
- 中：存在清晰场景和重复反馈，但缺少行为或数据验证。
- 低：单一反馈、转述、内部判断或推断。
- 冲突：不同来源给出相反结论。

可信度不等同于优先级。高风险、低频问题也可能需要优先处理。

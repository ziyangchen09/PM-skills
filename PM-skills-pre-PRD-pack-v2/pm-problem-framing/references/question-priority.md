# 待验证问题优先级

只保留会改变以下内容的问题：

- 问题是否真实；
- 目标用户；
- 核心场景；
- 影响规模；
- 原因判断；
- 解决方案空间；
- MVP 范围；
- 合规和安全边界；
- 是否值得进入 PRD。

按优先级分类：

## P0：问题定义阻塞

不确认就无法知道要解决什么，例如：

- 目标用户完全不明确；
- 当前表现和预期表现均不明确；
- 不知道问题发生在产品、流程还是算法；
- 不同来源对核心问题相互冲突。

## P1：会改变方案或范围

例如：

- 高频用户和低频用户的流程不同；
- 问题只发生在特定数据条件；
- 当前绕行方式是否可接受；
- 影响是效率问题还是安全问题。

## P2：可在方案或 PRD 阶段补充

例如：

- 具体文案；
- 非核心展示顺序；
- 次要异常提示；
- 视觉偏好。

默认不向用户连续提出全部问题。先输出分析，再提出一个最重要的问题。

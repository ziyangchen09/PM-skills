# 需求变更影响规则

## 比较

先运行：

```text
node scripts/analyze-prd-change.js --root <pm-knowledge> --old <旧版> --new <新版> --output <证据包>
```

证据包按 Markdown 章节标记 `新增`、`修改`、`删除`，统计未变章节，并召回可能相关的历史资料。脚本只提供文本证据，不判断业务影响。

## 搜索影响

基于每个 `CHG-ID` 检查：

- 用户流程和帮助文案
- UI 状态、组件与原型说明
- API、数据模型、缓存和权限
- 埋点、指标与实验
- 测试用例、发布说明、迁移和回滚
- 依赖该规则的其他 PRD 与决策

关键词命中、相似名称或同一项目只能证明“可能相关”。只有直接引用、明确依赖或同一数据/API/规则关系才能标记为 `确定`；其他均标记 `待核实`。

## 输出

```text
变更ID | 影响领域 | 受影响对象/文档 | 证据来源 | 风险 | 建议更新 | 状态（确定/待核实）
```

另输出：

```text
文档路径/名称 | 建议更新章节 | 依据 | 负责人 | 状态
```

建议必须指出具体文档和章节。默认只给更新建议并保存新的影响报告，不直接改写关联文档或飞书原文。

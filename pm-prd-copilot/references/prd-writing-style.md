# PRD 写作风格

本次用户明确优先“少套话、少重复，功能描述更像我平时写的”。以下是结合明确改稿意见与历史归档提炼的默认写法，可被本轮要求覆盖。优先级：本轮原文/指令 > 用户明确认可或修改的样例 > 同项目可靠历史样例 > 以下默认规则。不要宣称推断出的偏好已被用户逐条确认。

## 写到用户需要的粒度

- **局部改写**：保留原章节、表头、编号和用词，只改点名部分。用户只要功能概述，就交付对应表格；不要顺带扩写背景、验收矩阵、风险清单或结尾总结。
- **增量需求**：用一句背景交代“在什么基础上补充什么”，基线集中引用一次。范围表按用户目标组织功能，新增/调整规则放到对应详情；不重写已评审的命名、字段和关联规则。
- **整篇工作稿**：优先沿用提供的样稿。无样稿时，可用“一、版本说明；二、字段解释；三、需求背景；四、需求范围；五、需求详情”的历史结构，删去没有实际内容的可选节；没有修改人、版本或优先级依据时不填造。需求详情按功能组织，入口、规则、异常、退出等只在适用处展开。不能把“简洁”理解成只给范围表。
- **正式流程**：使用受控模板，保留必需的故事、验收、风险与确认表。范围写概述、详情写规则、验收写可观察结果，通过引用连接，避免每节重述同一套内容。

功能数量取决于本轮目标；历史上要求“两个功能”是一次局部指令，不是以后所有 PRD 的固定数量。优先级只沿用当前输入或适用的可靠基线，不能因为历史里常见 P0 就默认填 P0。

## 句子如何写

- 用“当前存在的具体问题 → 本次调整”交代背景，通常一小段即可。不扩写行业背景或空泛收益。
- 常用句式：“点击【控件】后，显示/隐藏/切换……”“当……时，……”“保存后，……”“退出后，恢复……”。优先写动作和结果；沿用现有控件名，原文没有特殊格式时不强制统一改成【】。
- 范围表的一行只说明一个功能的用途和关键边界。概述以一两句为起点，复杂规则另放详情；不用固定字数截掉必要条件。
- 调整现有行为时，只有对比能消除歧义才写“原逻辑 / 调整后”；不是每条需求都要配一组。
- 避免“赋能、打造闭环、提升体验、智能化升级”等无具体规则的句子。字段名、按钮文案和业务概念保持准确，不为换词而换词。
- 不加用户未要求且无依据的接口、数据库、算法、尺寸、快捷键、时长、阈值或埋点；如果影响本轮实现，就明确写待确认。

## 配图与图位

- 写 PRD 时，在需要用图说明的正文位置预留图位，紧跟对应流程或功能描述，不只在文末列配图清单。按实际需要选择页面截图、原型图、流程图、交互状态图或前后对比图，不要求每节都放图。
- 图位用独立、可见的文字标记：`【图位：图名｜放图内容：图类型及具体页面、流程或状态｜关键标注：需突出展示的入口、区域、步骤或差异】`。说明应让补图的人知道具体放什么，不能只写“此处放图”或“截图”。
- 例如：`【图位：日志筛选操作示意｜放图内容：日志页面原型图，展示筛选入口与筛选后的列表｜关键标注：筛选入口、当前筛选条件、结果区域】`。示例仅说明格式，真实图位只写本轮有依据的内容。
- 已有合适图片时保留图片及图注；缺少图片时保留图位，不编造图片路径或声称图片已插入。图位不能替代正文中的业务规则，也不意味着已经生成或验证原型。
- 局部改写只处理本轮范围内的图位。用户限定表格输出时，将必要图位写在对应说明单元格中，保留原表头；本轮明确不要配图时按本轮要求执行。

## 事实和待确认项

起草时先分清本轮已知、适用基线、建议与未定规则，不必把这套分析过程逐项展示给用户。正文只写有依据的规则；待确认项集中列一次，并说明具体缺什么、影响哪个行为。非本轮范围的细节不追问。

示意：“待确认：保存失败后是否保留已编辑内容，影响重试时的表单恢复。”不要只写“异常处理待完善”。确实阻碍选择正确方向时再提问；其余先交付能确定的正文。不把一句“继续”解释成用户已确认你新增的业务规则。

用户已说明基线通过评审时，保留这个前提；本地缺少门禁文件只影响正式校验资格。尚未验证的匹配算法、外部依赖或原型交互单独标记，不能把它们或整个基线写成新的确认结论。

日常复制稿优先用纯文本“待确认”；需要飞书低亮度红色提示或进入正式模板时使用 `<span style="color:#A65A5A">待确认：具体内容</span>`，不支持 HTML 时仍保留文字。

## 小例子

以下为写法示例，不是可跨项目套用的产品规则。

输入：“增加日志筛选，按操作类型筛选；其他规则同现有日志功能。只写功能和功能概述。”

| 功能 | 功能概述 |
| --- | --- |
| 日志筛选 | 支持按操作类型筛选日志，其他规则沿用现有日志功能。 |

不要追加“建设完整的操作追溯闭环”、自动补出筛选选项或新增导出功能。真实项目引用“现有日志功能”时，应使用已提供的名称/章节/链接；缺少来源不能编造编号。

输入：“把 5.2 里的进入/退出行为补清楚：进入对比模式隐藏工具，退出恢复；其他段不动。”

沿用 5.2 的标题，只补：“进入对比模式后，隐藏【工具】入口；退出后恢复显示。”不扩写状态机、权限或关闭后的数据清理规则。
